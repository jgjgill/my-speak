# 1단계: 한글 스크립트

안녕하세요, **요리 수업**{cooking class}에 왔어요.
네, **예약하셨나요**{did you make a reservation}? 성함이 어떻게 되세요?
네, **홍길동**{Gildong Hong}이라고 합니다. **제 이름은 등록되어 있나요**{is my name registered}?
네, **등록되어 있습니다**{yes, it is registered}. **앞쪽 자리에 앉으시면 됩니다**{you can sit at the front desk}.
**감사합니다**{thank you}. **이 수업은 무엇을 배우나요**{what will we learn in this class}?
오늘은 **이탈리아 파스타**{Italian pasta} 만드는 법을 배웁니다.

# 2단계: 외국어 스크립트

Hello, I'm here for the cooking class.
Yes, did you make a reservation? What is your name?
Yes, my name is Gildong Hong. Is my name registered?
Yes, it is registered. You can sit at the front desk.
Thank you. What will we learn in this class?
Today, we will learn how to make Italian pasta.
