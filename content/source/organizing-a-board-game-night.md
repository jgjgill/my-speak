# 1단계: 한글 스크립트

이번 주말에 **보드게임 밤**{board game night}을 할까요?
좋아요! **언제가 괜찮아요?**{What day works for you?}
**토요일 저녁은 어때요?**{How about Saturday evening?}
토요일 좋아요. **어떤 게임을 할까요?**{What games should we play?}
저는 **카탄과 티켓 투 라이드**{Catan and Ticket to Ride}가 있어요. **다른 거 있어요?**{Do you have any others?}
**익스플로딩 키튼**{Exploding Kittens}도 있어요. 그것도 할 수 있어요.
좋아요! **몇 시에 시작할까요?**{What time should we start?}
**저녁 7시쯤**{around 7 PM} 시작합시다.
