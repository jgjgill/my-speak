# 1단계: 한글 스크립트

정말 수고 많았어요. 프로젝트 결과가 아주 좋았어요.
**다음 발표에서는**{For the next presentation,} 데이터 시각화를 좀 더 신경 쓰면 어떨까요?
어떤 점을 개선하면 좋을지 구체적으로 말해줄 수 있나요?
**표를 사용하기보다는 차트를**{charts rather than tables} 더 많이 활용하면, 사람들이 데이터를 이해하기 훨씬 쉬울 거예요.
그 제안 아주 좋아요. **다음 프로젝트에 꼭 반영할게요.**{I will definitely incorporate that into the next project.}

# 2단계: 외국어 스크립트

You worked really hard. The project results were very good.
For the next presentation, how about we pay more attention to data visualization?
Can you tell me specifically what could be improved?
Using charts rather than tables more often would make it much easier for people to understand the data.
That suggestion is great. I will definitely incorporate that into the next project.

# 4단계: 키워드 스피치

## 레벨 1: 상세한 키워드 (70% 정보)

정말 수고 많았어요, 프로젝트 결과 아주 좋았어요 → You worked really hard. The project results were very good.
다음 발표, 데이터 시각화, 신경 쓰면 어떨까요 → For the next presentation, how about we pay more attention to data visualization?
구체적으로, 개선하면 좋을지, 말해줄 수 있나요 → Can you tell me specifically what could be improved?
표 대신 차트, 더 많이 활용, 데이터 이해 쉬울 것 → Using charts rather than tables more often would make it much easier for people to understand the data.
제안 좋아요, 다음 프로젝트, 꼭 반영할게요 → That suggestion is great. I will definitely incorporate that into the next project.
