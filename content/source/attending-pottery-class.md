# 1단계: 한글 스크립트

안녕하세요! 도예 수업에 오신 것을 환영합니다.
안녕하세요. 오늘 수업이 처음인데, **어떤 것부터 시작해야 할까요?**{What should I start with?}
걱정 마세요. 먼저 **기본적인 도구 사용법**{how to use basic tools}을 알려드릴게요.
네, 좋습니다. **준비물은 다 챙겨왔어요.**{I brought all the necessary supplies.}
잘하셨어요. 그럼 **흙을 만져볼 준비**{ready to touch the clay}를 해볼까요?
네! **얼른 만들어보고 싶어요.**{I can't wait to try making something.}
좋아요. **작은 그릇부터 시작**{Let's start with a small bowl}해봅시다.
